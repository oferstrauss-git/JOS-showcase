### 5\. 🤖 JOS (Agentic Job Search Automation Pipeline)

An automation system I built and run daily. It sources job postings from Gmail alerts, Indeed, and direct board scraping, filters and qualifies them through a two-stage pipeline (including an agent-driven check for whether a required skill is a hard requirement or a soft mention), drafts tailored CVs and cover letters, and finds warm LinkedIn contacts at each company, then puts everything in front of me to approve. Nothing is ever submitted automatically.

**Tools:** Node.js · Express · React · Claude Code (Agent SDK) · Model Context Protocol (Gmail, Sheets, Docs, Playwright)
